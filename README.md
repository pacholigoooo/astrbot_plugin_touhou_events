# 东方活动日历

给 AstrBot 群聊使用的东方展会、茶会和高校例会查询插件。作者：pachi。适用 AstrBot 4.26，使用 THBWiki 的公开活动接口，无需账号、API Key 或模型调用。

在 AstrBot 插件管理中选择「从链接安装」，填入本插件的 [GitHub 仓库地址](https://github.com/pacholigoooo/astrbot_plugin_touhou_events)：

```text
https://github.com/pacholigoooo/astrbot_plugin_touhou_events
```

也可以选择「从文件安装」，上传 `astrbot_plugin_touhou_events-v1.0.0.zip`，或把本仓库放到 `data/plugins/astrbot_plugin_touhou_events`，启用插件即可。没有额外 Python 依赖。

## 指令

| 指令 | 查询内容 |
| --- | --- |
| `/东方活动` | 中国，从今天起30天 |
| `/东方活动 武汉 本周` | 本周武汉的活动 |
| `/东方活动 江苏 未来60天` | 从今天起60天内江苏省的活动 |
| `/东方活动 2027-01` | 2027年1月 |
| `/东方活动 2027-01-01~2027-01-31` | 指定起止日期，包含首尾 |
| `/东方活动 茶会 未来90天` | 以关键词筛选茶会 |
| `/东方活动 全部 第2页` | 全部地区的第2页 |
| `/东方活动 海外` | 海外活动；也可填「线上」「待确认」 |
| `/东方活动详情 1` | 自己在当前会话上次查询中，第1个结果的详情 |
| `/东方活动出处 1` | 第1个结果对应的原始词条 |
| `/东方活动出处` | 数据源与许可 |
| `/东方活动 帮助` | 查看帮助 |

`/东方去哪玩` 是 `/东方活动` 的别名。多个地点或关键词需同时匹配，可与时间、范围、页码组合，参数用空格分隔。省份支持按已识别的活动城市匹配；城市查询仍按该城市本身匹配。

日期按北京时间计算。本周指周一至周日，包含本周已过去的日期；下周指下一个周一至周日。`未来N天` 包含今天，支持1至180天。自定起止日期单次最多366天，也可查看往期活动。每页6场，回复会明确写出实际查询起止日期。

跨天活动只要覆盖查询日期就会显示，末日包含在内。接口只按活动开始日期检索，因此插件回溯至查询起始月份的前月月初，再本地判断日期相交；在这之前开始的超长活动不在本次收录范围。上游单次最多200条，达到上限时自动细分日期，避免把截断的列表当成完整结果。

详情序号从每页的1开始，按发送者与当前会话隔离，保留30分钟；重启插件后重新查询即可。插件不主动向群聊推送消息。

## 地点与资料范围

中国范围包含港澳台。地点取自 THBWiki 返回的「于……举办」文字，省份及常见城市的识别口径参考东方工具箱，补充了吉安、锦州等当前活动城市。来源未提供地点、或只有无法识别的场馆名时归入「地点待确认」，可用 `/东方活动 待确认` 查看。不会根据活动名称推定举办城市。

日历覆盖的是社区已收录资料，查询为空表示来源在该筛选范围暂无记录。活动的开场时间、票价、是否改期或取消，以及最新入场要求，请查看词条中的主办方公告。公开 JSON 接口提供活动日期，插件不会把全天日期说成实际开场时刻，也不会推定活动已获主办确认。

## QQ 官方机器人

活动列表与详情使用纯文本，关闭 Markdown 和转图片，不夹带外部链接。出处通过独立的 `/东方活动出处` 查询。QQ 官方适配器默认提供 THBWiki 词条名，可在 THBWiki 按词条检索。

如已在 QQ 机器人后台配置来源域名，可在插件配置的 `qq_link_domains` 中填写对应域名，例如 `thwiki.cc`、`thbwiki.cc`、`calendar.thbwiki.cc`，使出处命令发送对应链接。其他平台的出处命令直接提供原词条链接。

## 数据源与许可

- [THBWiki 日程表](https://thwiki.cc/日程表) 明确推荐公开事件日历服务。
- [公开 API 文档](https://calendar.thbwiki.cc/)；查询接口是 `GET /api/events/YYYY-MM-DD/YYYY-MM-DD`。
- [ICS 订阅](https://calendar.thbwiki.cc/api/ics)。本插件直接使用 JSON 的日期、标题、地点说明、类型和词条链接。
- [官方 API 源码](https://github.com/thwiki/calendar-api-serverless)，MIT 许可。
- THBWiki 页面文字按 [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/deed.zh) 提供，引用作品版权归原作者。插件代码采用 MIT，参见 [LICENSE](LICENSE)。

联网请求由 Python 标准库处理系统 HTTPS 代理和代理认证，保留 TLS 证书校验；单次连接超时12秒，网络错误或服务器5xx时仅尝试一次已核实的 THBWiki 另一公开域名 `calendar.thwiki.cc`。成功查询（含空列表）在内存缓存5分钟；失败不缓存、不冒充空结果。缓存最多32个日期范围，不落盘。活动查询按日期范围合并复用，不会因每个城市重新抓取同一份日历。

## 验证

`scripts/check_plugin.py` 检查日期边界、城市与省份筛选、未知地点、多人会话序号隔离、缓存与失败提示，并用 AstrBot 4.26 的真实指令过滤器及 QQ WebSocket/Webhook 适配器验证纯文本序列化。加 `--live` 可查询真实 THBWiki 数据。脚本需在安装了 AstrBot 4.26 的环境运行，也可通过 `--sdk-root` 和 `--dependencies` 指定现有 SDK 与依赖目录。
